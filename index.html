📖 使い方

1. フォームに入力

地方を選択すると、その地方の市区町村データが読み込まれ、入力欄に候補がサジェストされます。

2. 空模様を検索

「空模様を検索する」ボタンを押すと、該当する位置情報から当時の詳細な天気を再現します。

📱 スマホへの追加方法（PWA）

iPhone(Safari): 共有ボタン →「ホーム画面に追加」
Android(Chrome): メニュー(⋮) →「ホーム画面に追加」

ℹ️ 気象情報源について

Open-Meteo API を利用し、1940年以降の全球気象データを再現しています。
