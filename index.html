ℹ️ データ出典・使用技術について

当アプリは以下のオープンデータおよびAPIサービスを利用して過去の気象・地名データを取得しています。


【使用しているデータ・API】
  • 気象データ: Open-Meteo Historical Weather API
  • 地名・位置情報: 国土地理院 ジオコーディングAPI / Open-Meteo Geocoding API

※ 旧市町村名（合併前地名）で検索した場合、現在の対応する市区町村名を自動判定して併記・検索します。
