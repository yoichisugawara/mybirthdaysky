使い方 (1/3): 条件の入力

1. 最初に**「地方」**を選択します。
2. 次に生まれた**「市区町村」**を入力し、出てくる候補一覧からタップして選びます。
3. 生年月日（1940年以降）を選択します。

使い方 (2/3): 結果の確認

「空模様を見る」を押すと、指定した日の**天気・最高/最低気温・降水量**が瞬時に計算されて表示されます！

使い方 (3/3): 結果のシェア

「結果をシェアする」ボタンを押すと、スマホの標準共有シートが開き、LINEやSNSでお友達や家族に生まれた日の天気をシェアできます！

ℹ️ データ出典・使用技術について

地方別に分割されたローカル地名データベースと、気象APIサービスを利用して過去の気象データを高精度に計算します。

  • 位置情報: 8地方別JSONファイル
  • 気象データ: Open-Meteo Historical Weather API
※本サービスでは過去の公的な再解析気象データを使用しておりますが、局地的な天候の違いや特定の時間帯、詳細な場所によって実際の天気と差異が生じる場合があります。あらかじめご了承ください。
