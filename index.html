ℹ️ データ出典・使用技術について

当アプリはオープンデータおよび気象APIサービスを利用してピンポイントな位置情報と過去の気象データをリアルタイム取得しています。


【使用データ・API】
  • 位置情報（ジオコーディング）: OpenStreetMap (Nominatim)
  • 過去の気象データ: Open-Meteo Historical Weather API

※平成の大合併等で広いエリアとなった市区町村でも、町名・地区名を入力することで標高や地域差を反映したピンポイントな天気を計算します。
