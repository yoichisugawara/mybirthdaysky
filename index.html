ℹ️ データ出典・使用技術について

当アプリは以下のオープンデータおよびAPIサービスを利用して過去の気象・地名データを取得しています。


【使用しているデータ・API】
  • 気象データ: Open-Meteo Historical Weather API（過去の再解析気象データ）
  • 位置情報・地名検索: 国土地理院 ジオコーディングAPI / Open-Meteo Geocoding API

※ 過去の天気データは当時の観測所および数値解析モデルに基づいているため、局地的な実際の天気と若干異なる場合があります。
